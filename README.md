# GitHub Finder

发现值得关注的 GitHub 好项目，并按领域分类汇总。

## 定位

这个仓库用于沉淀对开源项目的快速分析，重点回答三个问题：

1. 这个项目是做什么的？
2. 它的核心实现原理是什么？
3. 它是否值得关注，适合什么人关注？

## 分类

### AI / Agent

- [stripe/ai](projects/ai/stripe-ai.md): Stripe 官方面向 AI Agent 的 SDK、MCP、插件和技能集合。

## 收录标准

- 项目有明确应用场景或工程价值。
- 项目实现方式有参考意义。
- 项目活跃度、作者背景、生态位置或技术路线值得跟踪。

## 分析模板

每个项目分析默认包含：

- 一句话结论
- 项目功能
- 实现原理
- 技术栈与目录结构
- 是否值得关注
- 适合/不适合的人群
- 数据依据
